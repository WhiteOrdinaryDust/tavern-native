# 把代码托管上去（第一次做软件看这份）

## 先理解一件事

「开源」= 把源码放到一个公开的 Git 仓库（GitHub / Gitee 都行）✓。
本仓库**已经准备好**：`LICENSE`(GPL-3.0) ✓、`README.md` ✓、`signing/`(公开签名密钥) ✓、`.github/workflows/release.yml`(打 tag 自动出包) ✓、分支 `main` ✓、3 个提交 ✓。

## 路线 A：Gitee（码云）—— **国内直连，不用梯子** ✅

1. 打开 https://gitee.com → 注册/登录 → 右上「+」→「新建仓库」
2. 仓库名填 `tavern-native`，**不要**勾选「初始化仓库」（README/.gitignore/许可证都别勾 ✗，否则首次推送会冲突）
3. 建好后复制地址，形如 `https://gitee.com/你的用户名/tavern-native.git`
4. 生成**私人令牌**：头像 →「设置」→「安全设置」→「私人令牌」→ 新建，勾选 `projects` 权限 ✓ → 复制那串令牌（**只显示一次** ✓）
5. 把「用户名 + 令牌」给我，我来推送 ✓（用完你可以随时在页面**撤销**该令牌 ✓）

> ⚠️ 两点如实提醒：Gitee 对公开仓库有**实名认证**与**内容审核** ✓ —— 这个项目是角色扮演类 ✓，若被判定为敏感内容可能被限制 ✓；介意的话走路线 B ✓。

## 路线 B：GitHub —— 标准做法，但**需要梯子** ⚠️

1. 先让机器能上 GitHub（开代理/VPN ✓）。开了以后告诉我，我会：
   - 探测你的本地代理端口 ✓
   - 配置 git 走代理（`git config --global http.proxy ...`）✓
2. 然后在 GitHub 建**空仓库** ✓（同样不要勾初始化 ✓）
3. 你给我仓库地址 ✓ → 我发起推送 ✓ → 屏幕打印一个**8 位设备码** ✓ → 你在已打开的 GitHub 页面粘贴确认 ✓ → 推送完成 ✓（**令牌不会出现在对话里** ✓✓）

## 推送完成后我会顺手做的

- 打第一个 tag（例如 `v0.71.0`）✓ → 触发 CI 自动构建并附上 APK ✓
- 在仓库里补齐 `CONTRIBUTING.md`（写清"fork 请改 applicationId + 自己的密钥"）✓
- 把 `README.md` 里的构建命令按平台再对一遍 ✓

## 附：手动推送的三条命令（你自己也能做）

```bash
git remote add origin <仓库地址>
git push -u origin main
git tag v0.71.0 && git push origin v0.71.0
```
