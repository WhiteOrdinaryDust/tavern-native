# 酒馆（Tavern）— 原生 Android 版

一个本地优先的 AI 角色扮演客户端：角色卡、世界书、多会话、群聊、流式回复。
纯 Kotlin + Jetpack Compose 重写（无 Python、无 WebView），核心逻辑与旧版逐条对照测试。

## 功能

- **角色卡**：导入 SillyTavern PNG / JSON 卡片，编辑全部字段，头像可导入并拖动缩放裁剪
- **会话**：多会话、自动标题、开分支、候选回复（◀ n/m ▶）、重写、编辑、复制、删除
- **世界书**：书 → 条目两层结构、文件夹、导入/导出 ST JSON、合并、未分类收容、书内与全库搜索
- **群聊**：建群、加人、成员顺序（决定"依次都回"的发言顺序）、禁言
- **联网**：先搜再答（Tavily / 博查 / 自定义端点）
- **前情提要**：达到阈值后自动压缩早期历史，长会话不忘事
- **Markdown**：标题、列表、表格、代码块、引用、分隔线、删除线（自研解析器，13 项测试）
- **外观**：四套主题、字号、字体、气泡配色与透明度、背景图取景框、顶栏/底栏透明度
- **上下文用量**：显示"上次实际发送"占比、tokens、缓存命中率

## 构建

```bash
# 需要 JDK 17 与 Android SDK（compileSdk 36 / buildTools 35）
./gradlew :domain:test          # 214 项核心单测
./gradlew :app:assembleRelease  # 正式包（自动签名）
```

产物：`app/build/outputs/apk/release/app-release.apk`

## ⚠️ 签名与安装（请先读这段）

**本项目故意公开签名密钥**（见 [`signing/`](signing/)），以便任何人都能构建**可以覆盖安装**的升级包。

这意味着：

1. 任何人拿到本仓库即可签出"同包名"的 APK，并能**直接覆盖安装**在已装本应用的设备上。
2. 因此**请只从你信任的来源获取安装包**，并尽量核对来源（源码 tag / CI 产物哈希）。
3. 如果你要发布自己的修改版，**建议改用你自己的 `applicationId` 与密钥** —— 这样可以与本应用并存安装，互不覆盖。

## 数据与隐私

- 所有角色、会话、世界书数据都保存在**应用私有目录**（Room 数据库），不上传任何服务器
- API Key 等设置同样只存在本地（受系统应用沙箱保护，**明文存储**，界面上打码显示）
- 与模型的通信只发往你自己填写的接口地址
